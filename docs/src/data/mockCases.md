# Mock Cases Data

## 概要
開発・テスト用のモック事例データ。
実際の営業事例を模した構造化データを提供し、検索機能のテストや UI確認に使用。

## データ構造
`Case[]` 型の配列として定義。各事例は以下の情報を含む：

## 含まれる事例分野
- 内装工事（VR技術、現場管理）
- 解体工事（AI活用、品質向上）  
- 電気工事（部材管理、最適化）
- 設備工事（IoT、生産性向上）
- 建築工事（リフォーム、顧客管理）

## 企業規模の分布
- 小規模企業: 〜50名
- 中規模企業: 50〜300名  
- 大規模企業: 300名〜

## 地域分布
- 主要都市圏（東京都、大阪府）
- 地方都市（愛知県、福岡県）

## タグの例
- 技術系: "DX推進", "IoT活用", "AI活用", "VR/AR"
- 業務系: "生産性向上", "品質向上", "コスト削減", "人材不足"
- 分野系: "工期短縮", "現場管理", "顧客満足"

## 使用目的
1. **検索機能テスト**: 各種フィルターの動作確認
2. **UI表示確認**: 実データでの表示レイアウト確認  
3. **パフォーマンステスト**: 大量データでの処理速度確認
4. **デモンストレーション**: 顧客デモでの実例表示

## データ更新指針
- 実際の営業事例を参考に定期更新
- 新機能追加時は対応するテストケースを追加
- 個人情報は含めずダミー企業名を使用

## 注意点
- 本番環境では実データに置き換え
- 機密情報は含まない
- 定期的な内容の見直しとアップデート
