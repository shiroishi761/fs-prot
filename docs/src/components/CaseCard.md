# CaseCard Component

## 概要
個別の事例を表示するカードコンポーネント。
検索結果の一覧表示で使用され、事例の要約情報と操作ボタンを提供。

## 主要機能
- 事例の要約情報表示
- 検索キーワードのハイライト表示
- 関連度スコアの視覚的表示
- お気に入りボタン（ハートアイコン）
- クリックでの詳細表示

## 依存関係
- `../types/case.ts` - SearchResult型定義

## Props
```typescript
interface CaseCardProps {
  searchResult: SearchResult;    // 事例データと検索情報
  onClick: () => void;           // カードクリック時の処理
  isFavorite: boolean;           // お気に入り状態
  onToggleFavorite: () => void;  // お気に入りトグル処理
}
```

## 表示要素

### 1. ヘッダー部分
- **事例タイトル** - 検索キーワードがハイライト
- **お気に入りボタン** - ハートアイコン（塗りつぶし/アウトライン）
- **関連度スコア** - 100%未満の場合のみ表示（色分け）

### 2. メタ情報（再編成済み）
- **1段目**: 地域情報
- **2段目**: 業種 + 企業規模
- **3段目**: 課題概要

### 3. 課題スニペット
- **課題の要約** - 3段目に配置、120文字まで表示
- **ハイライト対応** - 検索キーワードのマーク表示

### 4. 課題種別表示 + 登録日
- **最大4個の課題種別** - 左側に表示、関連度でハイライト
- **登録日** - 右側に表示、日本語形式
- **残りタグ数** - 4個を超える場合は"+N"で表示

### 5. フッター情報
- **マッチしたフィールド** - title, challenge, tags等
- **登録日表示** - 課題種別と同行に右寄せで表示

## 関連度スコアの色分け
```typescript
- 80%以上: 緑色（高関連度）
- 60-79%: 黄色（中関連度）  
- 40-59%: オレンジ（低関連度）
- 40%未満: 赤色（参考程度）
```

## ハイライト機能
検索結果で一致したテキストを`<mark>`タグでハイライト表示：
- タイトル内のキーワード
- 課題文内のキーワード
- マッチしたタグの強調表示

## お気に入り機能
- **ハートアイコン**: クリックでお気に入り状態をトグル
- **状態表示**: 塗りつぶし（お気に入り）/アウトライン（未選択）
- **イベント伝播停止**: カードクリックと独立した操作

## レスポンシブ対応
- **グリッド表示**: デスクトップで3カラム、タブレットで2カラム
- **リスト表示**: モバイルで1カラム
- **柔軟なレイアウト**: 長いタイトルや多数のタグに対応
- **再編成済みレイアウト**: 地域→業種/企業規模→課題の3段構成

## ホバー効果
- **シャドウ変化**: hover時に影を強く
- **カーソル変更**: pointer表示
- **ボタンハイライト**: お気に入りボタンの色変化

## 使用パターン
```typescript
<CaseCard
  searchResult={result}
  onClick={() => showDetail(result.case.id)}
  isFavorite={favorites.has(result.case.id)}
  onToggleFavorite={() => toggleFavorite(result.case.id)}
/>
```

## パフォーマンス考慮
- **テキスト切り詰め**: 長い文章の適切な省略
- **ハイライト最適化**: 不要なHTML生成を回避
- **イベントハンドリング**: クリック伝播の適切な制御
